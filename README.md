# CA-RNN

This repository develops the **Calibration-Aware Recurrent Neural Network (CA-RNN)** for multivariate probabilistic time-series forecasting. CA-RNN augments likelihood-based recurrent training with differentiable penalties that target calibration of the predictive distribution.

CA-RNN is best classified as a **calibration-aware conditional stochastic forecasting model**. The RNN parameterizes a conditional predictive distribution, and forecasts or future paths are generated by sampling innovations from that distribution. It is therefore probabilistic, stochastic, and sample-generating, but it is not claimed to be a latent-variable or likelihood-free deep generative model such as a diffusion model, normalizing flow, GAN, or VAE.

The project follows the methodological and experimental template of
*Calibration-Aware Bayesian Learning*, adapted from classification to continuous
sequential prediction. Its four-model adaptation is:

| Reference-paper role | Sequential model |
|---|---|
| Frequentist neural network | RNN |
| Bayesian neural network | Bayesian RNN (BRNN) |
| Calibration-aware neural network | CA-RNN |
| Calibration-aware Bayesian network | CA-BRNN |

The adaptation is not a direct reuse of classification ECE. Continuous multivariate forecasts require a calibration definition for joint predictive distributions and an additional check that forecast errors are not predictable over time.

## Research questions

The primary question is:

> How does augmenting a likelihood-trained Gaussian RNN with differentiable projected-PIT calibration penalties affect the calibration and predictive quality of one-step-ahead multivariate forecasts under an isolated innovation-scale shift, across chronological market regimes, and relative to likelihood-only and classical benchmarks?

The experiments address four supporting questions:

1. Across the prespecified calibration-weight grid, what tradeoff arises between projected calibration error and strictly proper predictive scores, marginal interval score, and point-forecast error?
2. What does removing the temporal PIT-moment penalty reveal about its effect on held-out sequential calibration error, Energy Score, marginal interval score, coverage, and point-forecast error?
3. Does CA-RNN add forecast value beyond the likelihood-only RNN and VAR–GARCH on the development and frozen external asset panels, and how does its performance relative to the RNN vary across four chronological market regimes?
4. In a replicated experiment that changes only test-innovation scale, how do
   analytic projected-PIT error, test NLL, Energy Score, variogram score,
   interval score, and MSE differences vary with severity?

## Predictive model

For a multivariate series $Y_t\in\mathbb R^d$, a GRU encodes the available history:

$$
h_t=\operatorname{GRU}_\theta(h_{t-1},Y_t).
$$

The predictive head returns a location vector and lower-triangular scale matrix:

$$
Y_{t+1}\mid\mathcal F_t
\sim
\mathcal N_d\left(\mu_\theta(h_t),L_\theta(h_t)L_\theta(h_t)^\top\right).
$$

Positive diagonal transformations of $L_\theta$ guarantee a positive-definite
covariance matrix. The implementation uses the joint Gaussian head because every
projected predictive CDF is analytic and differentiable. Heavy-tailed heads are
reserved for future work.

Equivalently, a one-step stochastic forecast can be generated as

$$
Y_{t+1}=\mu_\theta(h_t)+L_\theta(h_t)\varepsilon_{t+1},
\qquad \varepsilon_{t+1}\sim\mathcal N_d(0,I_d).
$$

This sampling representation is the sense in which CA-RNN generates forecasts; the calibration penalties modify the estimated conditional distribution rather than defining a separate latent generative process.

The ordinary RNN minimizes the proper negative log-likelihood objective

$$
\mathcal L_{\mathrm{NLL}}
=-\frac{1}{T}\sum_t
\log p_\theta(Y_{t+1}\mid\mathcal F_t).
$$

## Projected multivariate calibration

Correct univariate marginals do not guarantee a correct joint forecast. For fixed unit projection vectors $a_1,\ldots,a_R$, CA-RNN computes projected probability integral transforms

$$
U_{t,r}=F_{\theta,t,a_r}(a_r^\top Y_{t+1}).
$$

Under a correctly specified continuous forecast, $U_{t,r}$ is uniformly distributed for every projection. The projection set contains asset coordinates, an equal-weight portfolio, and reproducibly generated random directions.

The calibration objective is a smoothed finite-grid approximation to an
integrated CDF discrepancy. For grid values $q_g\in(0,1)$,

$$
\mathcal L_{\mathrm{cal}}
=
\frac{1}{GR}
\sum_{g=1}^G\sum_{r=1}^R
\left[
\frac{1}{T}\sum_t
\sigma\left(\frac{q_g-U_{t,r}}{\tau}\right)-q_g
\right]^2,
$$

where $\sigma$ is the logistic function and $\tau>0$ controls the differentiable approximation to the empirical CDF.

## Temporal PIT-moment calibration

Uniform PIT values can still contain temporal structure. CA-RNN therefore penalizes their lagged covariance:

$$
\mathcal L_{\mathrm{seq}}
=
\frac{1}{RK}
\sum_{r=1}^R\sum_{k=1}^K
\left[
\frac{1}{T-k}\sum_{t=k+1}^T
(U_{t,r}-1/2)(U_{t-k,r}-1/2)
\right]^2.
$$

The full frequentist objective is

$$
\boxed{
\mathcal L_{\mathrm{CA\text{-}RNN}}
=
\mathcal L_{\mathrm{NLL}}
+\lambda_{\mathrm{cal}}\mathcal L_{\mathrm{cal}}
+\lambda_{\mathrm{seq}}\mathcal L_{\mathrm{seq}}.
}
$$

Both calibration components are part of CA-RNN. Setting
$\lambda_{\mathrm{seq}}=0$ is used only as a loss-component ablation and is
described as CA-RNN with its temporal penalty removed.

## Bayesian formulation

The BRNN places a mean-field Gaussian variational distribution $q_\phi(\theta)$ over the recurrent and predictive-head parameters. Its calibration-aware variational objective is

$$
\boxed{
\mathcal L_{\mathrm{CA\text{-}BRNN}}(\phi)
=
\mathbb E_{\theta\sim q_\phi}
\left[
\mathcal L_{\mathrm{NLL}}(\theta)
+\lambda_{\mathrm{cal}}\mathcal L_{\mathrm{cal}}(\theta)
+\lambda_{\mathrm{seq}}\mathcal L_{\mathrm{seq}}(\theta)
\right]
+\frac{\beta}{N}
\operatorname{KL}\!\left(q_\phi(\theta)\Vert p(\theta)\right).
}
$$

The implementation samples one set of recurrent weights per sequence evaluation,
uses the reparameterization trick, and includes the KL term in both ordinary
BRNN and CA-BRNN training. A common KL weight is selected from
$\{10^{-4},10^{-3},10^{-2},10^{-1},1\}$ by posterior-predictive validation NLL
for the likelihood-only BRNN. The selected value is then held fixed for both
BRNN and CA-BRNN, so their comparison changes the calibration penalty without
also changing the KL regularization strength. Test observations do not
participate in selection. Within each candidate fit, posterior-mean-weight
validation NLL selects the checkpoint; across the restored candidates, a
50-draw posterior-predictive mixture validation NLL selects the KL weight. The
selected value in the reported four-model experiment is $\beta=1$. During
training, projected-PIT penalties are computed separately for each sampled
parameter vector and then averaged. Evaluation instead uses the full
posterior-predictive mixture, so the fitted objective is not described as the
mixture's calibration penalty.

## Experimental workflow

The experiment sequence parallels the calibration-aware Bayesian learning study
while separating development, frozen confirmation, and post-protocol work:

1. Establish controlled multivariate sequential data-generating processes.
2. Compare RNN, BRNN, CA-RNN, and CA-BRNN using matched architectures and splits.
3. Sweep $\lambda_{\mathrm{cal}}$ and plot calibration against predictive performance.
4. Compare nominal and empirical probabilities through PIT and coverage reliability plots.
5. Ablate the projected calibration and sequential PIT penalties.
6. Evaluate a frozen-model combined scale/correlation stress as exploratory
   development evidence.
7. Apply the frozen workflow to four financial return series.
8. Compare against historical-bootstrap, Gaussian-VAR, and
   VAR--GARCH joint-residual-bootstrap baselines.
9. Execute the frozen external-panel protocol in
   `docs/confirmatory_protocol.md` without post-result tuning.
10. Run the post-protocol isolated scale-shift experiment as a crossed design:
    50 independent DGP seeds, three neural-optimization seeds, and three
    predictive-simulation seeds.

All transformations and splits are chronological. Model selection uses validation data only. The fixed-budget temporal ablation instead compares every specification after exactly 100 epochs with checkpoint selection disabled. Calibration improvements are always reported with proper scores and interval widths to expose trivial widening.

## Evaluation metrics

The primary measures are:

- projected-PIT calibration error and Kolmogorov--Smirnov statistics;
- lagged PIT dependence;
- nominal interval coverage and reliability curves;
- interval width and interval score;
- multivariate Energy Score;
- dependence-sensitive variogram score;
- held-out NLL when a comparable predictive density is available;
- root mean squared error;
- numerical failures, training time, and seed sensitivity.

Coordinate PITs assess marginal distributions. Portfolio and random projections probe cross-series dependence. No individual diagnostic is treated as proof of joint calibration.

Primary comparison intervals combine synchronized optimization-seed/date-block
resampling with predictive-draw resampling. Conclusions use simultaneous
max-$|z|$ intervals for the prespecified seven-metric family rather than
pointwise intervals. The rolling-regime analysis additionally allocates the
family-wise error budget across its four prespecified regimes and three declared
model contrasts. The isolated
scale experiment independently resamples its crossed DGP, neural-seed, and
forecast-seed factors, so its uncertainty is not conditional on a single fitted
model or a single simulated panel.

## Distribution shift

The revised replicated shift experiment is configured to vary innovation scale
alone over 50 independent Gaussian autoregressive datasets. Each realization is crossed with
three neural-optimization seeds and three predictive-simulation seeds, producing
300 neural fits and 2,700 model--severity--forecast evaluations. An earlier
single-realization curve changes scale and contemporaneous correlation jointly
and is exploratory.
Replicated isolated correlation, tail, and mean-dynamics shifts remain future
work. Stress results do not participate in model fitting.

## Financial application

The empirical application uses daily adjusted prices for AAPL, JPM, XOM, and WMT beginning in 2007. The cleaned series are daily log returns. These assets provide a small but economically varied multivariate system spanning major market regimes.

Financial data are stored locally under `data/processed/` and are ignored by
Git. The financial-data workflow can use an existing clean panel or download a
new one through the optional `yfinance` dependency.

## Installation

From the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[dev,market]'
python -m ipykernel install --user --name innovcal --display-name "Python (innovcal)"
```

Run the tests with:

```bash
python -m pytest -q
```

In VS Code, select the **Python (innovcal)** kernel before running the
experiment sequence.

To regenerate the corrected intervals from retained forecasts and verify the
compact results package without refitting models:

```bash
python reproducibility/scripts/recompute_bootstrap.py --sync-source-results
python reproducibility/scripts/build_package.py
python reproducibility/scripts/verify_package.py
```

The bootstrap draws one common moving-block date path per replicate and applies
it to every selected optimization seed and method. Temporal-PIT lag products are
formed on the original contiguous sequence before resampling, so synthetic block
joins are not treated as observed adjacent dates.

## Current status

The developmental CA-RNN study is implemented and complete. It includes deterministic and mean-field Bayesian GRUs, full-covariance Gaussian predictive heads, projected-PIT calibration, sequential PIT regularization, leakage-safe data utilities, controlled DGPs, sample-based evaluation, matched experiments, dependence-aware uncertainty, and unit tests.

The validation-selected Bayesian comparison and crossed isolated-scale study
are complete. Their selected hyperparameters, realization-level outputs,
summary tables, and manuscript conclusions are recorded in the reproducibility
package.

The conventional-benchmark experiment adds the model ladder to the completed
financial forecasts. The external-panel replication is governed by the frozen
protocol in `docs/confirmatory_protocol.md`; its settings must not be modified
after inspecting its outcomes. Confirmatory outputs are kept separate from
developmental results. The dated protocol record, exact simulation equations,
data hashes, environment lock, saved-forecast manifest, corrected compact
results, and table-generation map are under `reproducibility/`.
